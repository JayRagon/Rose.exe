# Rose.exe

## Overview
This is the source code of a crackme which was developed in 2024 and uploaded to crackmes.one \
The code has been published un-refactored on purpose, with a few comments of my thoughts on the code looking back at it

Two .sln files are included, one which is Rose (the main part of this project which generates the base .exe file) and rosencryptor which is a post-processing .exe that allowed me to inject inline x64 assembly and use static encryption and more.
